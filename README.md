Set up the folder structure
Before touching GitHub, organize your files exactly like this. GitHub will read the README.md and display it automatically on your repo page.

bsam-tx/ ├── scanner.py ← main tool ├── requirements.txt ← dependencies ├── README.md ← shown on GitHub homepage ├── LICENSE ← MIT license ├── demo.svg ← terminal screenshot ├── .gitignore ← files Git will ignore └── wordlists/ └── full500.txt ← 517-path wordlist

⚠️
Important: Never upload files with real credentials, API keys, or passwords. Double check your .env and config files are in .gitignore.
Create a .gitignore file to exclude sensitive and unnecessary files:

.gitignore
# Secrets — never upload these .env *.key *.pem # Reports generated by the tool report.json results/ # Python __pycache__/ *.pyc venv/ .venv/ # OS files .DS_Store Thumbs.db

Push your code to GitHub
Open the terminal inside your project folder and run these commands in order. Replace YOUR_USERNAME with your GitHub username.
terminal — inside bsam-tx/ folder
# 1. Initialize Git in your project folder git init # 2. Stage all files git add . # 3. Check what will be uploaded (optional but recommended) git status # 4. First commit — this is the message that appears on GitHub git commit -m "🚀 Initial release — bsam TX v2.5 AI-powered vulnerability scanner" # 5. Rename main branch git branch -M main # 6. Connect to your GitHub repo (replace YOUR_USERNAME) git remote add origin https://github.com/YOUR_USERNAME/bsam-tx.git # 7. Push everything to GitHub git push -u origin main ✓ Your code is now live on GitHub!
